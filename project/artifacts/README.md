# Артефакты

После обучения здесь сохраняются:

- `text_complexity_model.json` - финальная модель с весами, словарем признаков и параметрами масштабирования;
- `metrics.json` - протокол разбиения, метрики baseline, метрики финальной модели и откалиброванные CEFR-пороги.

Артефакты небольшие и нужны для демонстрации API без повторной ручной настройки.
