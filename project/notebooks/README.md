# Ноутбуки

В этой папке лежит экспериментальная часть проекта.

- `01_eda_and_experiments.ipynb` - первичный анализ long-text англоязычного CEFR-датасета, описание baseline, финальной модели и метрик.

Основной исполняемый код вынесен в `src/text_complexity/`, поэтому notebook используется как отчет об EDA и экспериментах, а не как единственная точка запуска проекта.
