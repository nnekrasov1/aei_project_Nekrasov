# Тесты

Тесты проверяют ключевые части проекта:

- `test_features.py` - токенизация, слоги, признаки читаемости и CEFR-лексические признаки;
- `test_training.py` - обучение, метрики, корреляция Спирмена, сохранение, загрузка и прогноз модели;
- `test_service_contract.py` - правила перевода `score` в CEFR-уровни и укрупненные категории сложности.
- `test_service_runtime.py` - доступность веб-страницы сервиса и нормализация многострочного текста перед `/predict`.

Запуск из папки `project`:

```bash
python -m unittest discover tests
```
